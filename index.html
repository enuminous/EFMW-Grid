03 / Fixed decision rules

Claim audit, not code approval

SUPPORTED

EFMW meets the predeclared false-alarm constraint and beats every named comparator on held-out primary metric, with prespecified uncertainty rules, engineering guardrails, and an independently reproducible package. This still does not prove new physics.

NARROWED

A valid useful application remains, but the supposed EFMW-specific advantage disappears when replacing it with a classical model of comparable capacity.

DEAD

The defined performance claim is refuted or violates prespecified critical guardrails. Infrastructure, missing data, or independent-reproduction failure yields UNVERIFIED, not a false claim of success.

The browser demo is always UNVERIFIED for scientific purposes; it cannot assign an official supported/narrowed/dead verdict. An independent person must reproduce a frozen external benchmark from the package alone.

04 / Tutorial & provenance

How to conduct a defensible experiment

Procedure

  1. Freeze claim, primary metric, sensor selection, and false-alarm denominator in a commit.
  2. Pin feeder model, library versions, scenario generator, true drift onset/type/magnitude and seeds.
  3. Allow each comparator the same tuning budget and access to training data.
  4. Calibrate thresholds using training nulls only; do not touch holdout.
  5. Run held-out scenarios once; include missed detections and null windows.
  6. Archive raw records, aggregate statistics, checksums, command logs and uncertainty calculation.
  7. Request an independent clean-room rebuild before a scientific verdict.

Core recurrence and limitations

r[t] = y[t] - yhat[t]
m[t] = 0.97*m[t-1] + 0.03*r[t]
C[t] = abs(m[t])

In a scalar form this recurrence is an EWMA on signed residuals. Any advantage must survive equivalent classical memory and multivariate structure tests. Disturbance detection is not itself a transmission-efficiency outcome.
